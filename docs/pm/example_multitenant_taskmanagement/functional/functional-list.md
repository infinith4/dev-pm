## 1. 目的

- マルチテナント版の機能要件を一覧化し、スコープと優先度を可視化する
- 個別 FR 文書、SRS、Vision & Scope、トレーサビリティへの導線を提供する
- Release 1 で詳細化済みの機能と、今後詳細化が必要な機能を切り分ける

---

## 2. 記載ルール

### 2.1 ID 規約

- 機能IDは `FR-{連番3桁}` 形式とする
- 個別ファイル名は `FR-{連番3桁}-{機能名}.md` とする
- 一度採番した ID は削除後も再利用しない

### 2.2 優先度定義

- **Must**: Release 1.0 に必須
- **Should**: 重要だが Release 2 への移動可
- **Could**: あれば望ましい
- **Won't**: 今回のスコープ外

### 2.3 運用ルール

- 一覧に記載する機能は、対応する個別 FR 文書へのリンクを持つ
- `vision-and-scope.md` の主要機能と差分がある場合は備考欄に理由を明記する
- 関連 UC / US / BO が未作成または未確定の場合は `—` または `TBD` と記載する

## 5. レビュー観点

- すべての作成済み FR に一意の `FR-ID` と個別ファイルが存在するか
- 機能概要がユーザー価値または運用価値を説明しているか
- `vision-and-scope.md` の主要機能と一覧の差分が説明されているか
- SRS とトレーサビリティの参照先がこの一覧と矛盾していないか
- 未作成の個別 FR が Release 計画上妥当か
