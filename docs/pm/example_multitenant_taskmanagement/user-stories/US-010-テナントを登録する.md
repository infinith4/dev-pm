## ユーザーストーリー

> **As a** 新規顧客企業のテナント管理者
> **I want to** サインアップフォームに情報を入力するだけで、プラットフォーム管理者に連絡することなく TaskBoard テナントを作成したい
> **So that** 担当者の作業待ちなしに即日チームで使い始めることができるようにしたい

## 受入基準

### AC-001: 必要事項を入力してテナントを登録できる

```gherkin
Given テナント管理者が https://taskboard.jp/signup にアクセスしている
When  企業名「株式会社サンプル」、サブドメイン「sample」、
      メールアドレス「admin@sample.co.jp」、パスワード、プラン「Starter」を入力して「登録する」を押す
Then  確認メールが admin@sample.co.jp に送信される
  And 「確認メールを送信しました。メール内のリンクをクリックして登録を完了してください」と表示される
```

### AC-002: メール確認後に Azure リソースが自動プロビジョニングされる

```gherkin
Given テナント管理者が確認メールを受信している
When  確認メールのリンクをクリックする
Then  3分以内に以下が完了する:
      - テナント専用 PostgreSQL DB が作成されている
      - テナント専用 Blob Storage コンテナが作成されている
      - Azure Key Vault に接続文字列が登録されている
      - Stripe にトライアルサブスクリプション（14日間）が作成されている
  And オンボーディング完了メールが送信される
  And https://sample.taskboard.jp にログインできる状態になっている
```

### AC-003: オンボーディング完了まで 10 分以内

```gherkin
Given テナント管理者がサインアップページを開いた
When  フォーム入力からメール確認・ダッシュボードへのログインまでを完了する
Then  所要時間が 10 分以内である
```

### AC-004: 重複するサブドメインは登録できない

```gherkin
Given サブドメイン「sample」は既に別テナントが使用している
When  テナント管理者がサブドメイン「sample」でサインアップしようとする
Then  「このサブドメインは既に使用されています」とエラーが表示される
  And 代替候補（例: sample-2）が提示される
  And テナントは作成されない
```

### AC-005: 予約済みサブドメインは使用できない

```gherkin
Given テナント管理者がサブドメインに「admin」を入力する
When  「登録する」を押す
Then  「このサブドメインは使用できません」とエラーが表示される
  And テナントは作成されない
```

### AC-006: プロビジョニング失敗時はロールバックされる

```gherkin
Given メール確認が完了しプロビジョニングが開始されている
When  Azure リソース（DB）の作成に失敗した
Then  作成済みの Azure リソースがロールバック（削除）される
  And テナント管理者に「設定に問題が発生しました。サポートにお問い合わせください」と表示される
  And プラットフォーム管理者にアラートが送信される
  And テナントの Platform DB レコードはステータス「provisioning_failed」で残る（再試行のため）
```

### AC-007: 14 日間のトライアル終了前にリマインドメールが届く

```gherkin
Given テナントのトライアル期間が残り 3 日になった
When  システムが日次バッチを実行する
Then  テナント管理者にトライアル終了リマインドメールが送信される
  And メールにはプラン選択ページへのリンクが含まれる
```

## 補足・制約

- サブドメインは 3〜63 文字、英数字・ハイフン使用可、先頭は英字（BR-MT-10）。
- 確認メールのリンク有効期限は 24 時間（期限切れ時は再送可能）。
- プロビジョニングの最大待機時間は 3 分（NFR-PRF-03）。超過した場合はアラートを発報する。
- カード情報は Stripe に保存し、TaskBoard のシステムには保存しない（NFR-SEC-SEC）。
- 参照: [FR-010 Tenant.Provision](../functional/FR-010-テナント管理.md)、[UC-010](../use-cases/UC-010-テナントをオンボーディングする.md)
