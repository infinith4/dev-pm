## スケジュールリスク

| リスク | 影響フェーズ | 影響度 | 軽減策 |
|-------|-----------|-------|-------|
| Azure Batch の 100 万件/テナント負荷テストで性能不足が判明 | Phase 4 | 高 | Phase 2 の Spike（M2-03）で早期検証。Azure Batch Pool のノード数・VM サイズを確定 |
| 工場 SFTP ヒアリングが遅延し Phase 2 の工場連携設計が遅れる | Phase 2〜3 | 高 | Phase 1 中から工場担当者（SH-06）にヒアリングを開始済み（TBD-SRS-03 を 2026-04-30 までに解決） |
| Entra ID Graph API の制限で自動プロビジョニング設計が変更になる | Phase 2〜3 | 中 | Phase 2 の M2-02 で Spike 検証。手動フォールバック設計を並行して準備 |
| 工場ごとのフォーマット定義の変更要求が多発し工場連携実装が遅延 | Phase 3 | 中 | フォーマット定義をデータベース管理にし、管理画面から変更可能にする（NFR-MAINT-02） |
