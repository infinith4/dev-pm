## ユーザーストーリー

**As a** テナント A の EC サイトを訪れた消費者

**I want to** 商品を検索・選択してカートに追加し、Stripe でクレジットカード決済を完了したい

**So that** 自宅に商品を届けてもらい、翌朝には工場で製造準備が始まっている安心感を得たい

---

## 受入基準

### AC-001: CIAM 認証でのログイン

**Given** テナント A の EC サイト（`shop.myshop.jp`）にアクセスしている

**When** CIAM のメールアドレス＋パスワードでログインする（または Google ソーシャルログインを使う）

**Then**
- テナント A 専用の Azure AD External Identities（CIAM）で認証され、JWT が発行される
- JWT の `iss` クレームにテナント A の Entra ID テナント ID が含まれる
- テナント A の EC サイトのみアクセスでき、テナント B の EC サイトにはこのアカウントでアクセスできない（BR-EC-01）

### AC-002: 商品検索・カートへの追加

**Given** EC サイトにログイン済みの消費者

**When** 商品名「商品A」で検索し、在庫ありの商品をカートに追加する

**Then**
- Azure Cognitive Search（テナント A のインデックス）が商品を検索し、300ms 以内に結果を表示する
- 在庫ありの商品がカートに追加される
- カートデータが Redis に保存され、デバイスをまたいで引き継げる（BR-EC-10）
- 在庫切れの商品はカートに追加できない（BR-EC-11）

### AC-003: ゲスト購入

**Given** CIAM アカウントを持たない消費者

**When** 「ゲストとして購入」を選択し、メールアドレスを入力してチェックアウトを完了する

**Then**
- CIAM アカウントなしで注文が完了する
- 注文確認メールがゲストのメールアドレスに送信される（BR-EC-02）
- 注文データはテナント A の DB に正常に保存される

### AC-004: Stripe 決済の完了

**Given** カートに商品（SKU-001 x 3 個、¥1,500/個）が入っており、配送先住所を入力済みの消費者

**When** Stripe カード入力フォームにクレジットカード情報を入力し「注文を確定する」をクリックする

**Then**
- 在庫が仮確保される（BR-EC-12）
- Stripe Payment Intent が成功し、合計 ¥4,500 が決済される
- カード番号はシステム内に保存されない（BR-EC-13）
- 注文が `confirmed` 状態でテナント A の DB に保存される
- 注文番号 `myshop-20261201-XXXXXXXX` が発行される（BR-EC-14）
- 注文確認メールが消費者に送信される

### AC-005: 在庫・決済の例外処理

**Given** 商品の在庫が 2 個しかない状況

**When** 消費者が 3 個カートに追加しようとする

**Then**
- システムが在庫不足を検知し「在庫が 2 個しかありません」と表示する（BR-EC-11）
- カートに 3 個は追加されない

**Given** Stripe 決済が失敗した（カードの残高不足）

**When** 「注文を確定する」をクリックする

**Then**
- 在庫仮確保が解除される（BR-EC-12）
- カートの内容は維持される
- 「カードが拒否されました。別のカードをお試しください」が表示される

### AC-006: テナント分離の保証

**Given** テナント A の CIAM で認証済みの消費者

**When** テナント B の EC サイト（`shop.othershop.jp`）にアクセスしようとする

**Then**
- テナント B の CIAM での再認証を要求される（テナント A のセッションは無効）（BR-EC-01, FR-011）

**Given** テナント A の注文が正常完了した

**When** 当日 22:00 の夜間バッチが起動する

**Then**
- テナント A の注文データのみがテナント A のバッチジョブで処理される
- テナント B の工場にテナント A のデータが送信されない（BR-FACTORY-09, FR-011）

---

## 技術メモ

- **CIAM**: テナントごとに専用の Azure AD External Identities テナントを使用
- **検索**: Azure Cognitive Search テナント別インデックス（`shop-{tenant_id}`）
- **カート**: Azure Cache for Redis（キー: `cart:{consumer_id}`、TTL: 30 日）
- **決済**: Stripe Elements + Payment Intent API（PCI DSS 準拠）
- **性能**: ピーク時 10,000 req/sec 対応（Azure Front Door + Container Apps Auto Scaling）
