## 機能要件一覧

| FR-ID | 機能名 | 説明 | 優先度 | Vision & Scope | 関連 BR | ドキュメント |
|-------|-------|------|-------|---------------|---------|------------|
| FR-001 | EC サイト（消費者向け） | 消費者が商品を閲覧・購入するフロントエンド EC サイト。CIAM 認証・Stripe 決済・日次 1,000 万件対応（全テナント合計、ピーク 10,000 req/sec）。Azure Cognitive Search による商品検索・Redis によるカートセッション管理を含む。 | Must | FE-3, FE-9 | BR-EC-01〜BR-EC-15 | [FR-001-ECサイト.md](FR-001-ECサイト.md) |
| FR-010 | テナント管理（Entra ID プロビジョニング） | テナントの登録・設定・工場設定・ライフサイクル管理。Microsoft Graph API で Entra ID テナント・CIAM・OIDC アプリ・DB・Blob コンテナ・カスタムドメインを 20 分以内に自動プロビジョニング。 | Must | FE-1, FE-5, FE-8 | BR-MT-01〜BR-MT-05, BR-MT-10〜BR-MT-13, BR-MT-30〜BR-MT-35, BR-MT-40〜BR-MT-42 | [FR-010-テナント管理.md](FR-010-テナント管理.md) |
| FR-011 | テナントデータ分離 | Entra ID テナント分離・JWT iss クレーム検証・Azure Front Door ルーティング・テナント別 PostgreSQL DB（Bridge モデル）・テナント別 Blob コンテナ・バッチジョブ分離・API テナントスコープ保証・監査ログ。 | Must | FE-2 | BR-MT-20〜BR-MT-24, BR-MT-50〜BR-MT-51 | [FR-011-テナントデータ分離.md](FR-011-テナントデータ分離.md) |
| FR-020 | 注文キュー駆動バッチ処理（常時工場データ連携） | 注文確定時に order-batch-queue へ自動投入。常時稼働 Azure Batch ワーカーが (tenant_id, factory_id) 単位で集約し、SizeFlush（1,000 件）/ TimeFlush（30 分）で CSV 生成・工場転送。テナントあたり最大 100 万件/日・全テナント合計 1,000 万件/日対応。 | Must | FE-6 | BR-BATCH-01〜BR-BATCH-10 | [FR-020-注文キュー駆動バッチ処理（常時工場データ連携）.md](FR-020-注文キュー駆動バッチ処理（常時工場データ連携）.md) |
| FR-021 | 工場データ連携（CSV 生成・SFTP 配布） | 工場マスタ・フォーマット定義に基づき CSV/TSV を生成（エンコーディング・区切り文字・列定義に対応）。PGP 暗号化（オプション）。SFTP（SSH キー認証）または Azure Blob（SAS URL）で配布。転送ログ記録・工場システムへの完了通知（Webhook/メール）。転送失敗時の自動リトライ（3 回）。 | Must | FE-7 | BR-FACTORY-01〜BR-FACTORY-10 | [FR-021-工場データ連携.md](FR-021-工場データ連携.md) |
| FR-022 | 工場出荷完了通知受信・注文ステータス更新 | 工場がCSVデータを受け取り数時間後に出荷完了したら、ShopHub の Webhook エンドポイントに通知を送信。HMAC-SHA256 署名検証・テナント分離確認・冪等性チェック後、注文ステータスを `shipped` に更新。消費者に発送通知メール送信（追跡番号含む）。管理サイトへのリアルタイム反映。受信ログ記録。 | Must | FE-7 | BR-FACTORY-11〜BR-FACTORY-15 | [FR-022-工場出荷完了通知受信.md](FR-022-工場出荷完了通知受信.md) |

## 機能間の依存関係

```
FR-010（テナント管理）
  └─ FR-011（テナントデータ分離）
        ├─ FR-001（EC サイト）
        │     └─ FR-020（夜間バッチ処理）[注文データの抽出元]
        │           └─ FR-021（工場データ連携）[バッチ後の配布]
        │                 └─ FR-022（工場出荷完了通知受信）[工場→ShopHub の逆フロー]
        └─ 管理サイト（FR-010 の一部として定義）
```
