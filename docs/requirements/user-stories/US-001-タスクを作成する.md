## ユーザーストーリー

> **As a** プロジェクトマネージャーまたは開発者
> **I want to** プロジェクト内にタイトル・担当者・期限・優先度を指定して新しいタスクを作成したい
> **So that** チームメンバーが何をすべきかを明確に把握し、抜け漏れなく作業を追跡できるようにしたい

## 受入基準

### AC-001: タイトルと最低限の情報でタスクを作成できる

```gherkin
Given 認証済みユーザー（PM または開発者）がプロジェクト画面にいる
When  タイトル「ログイン画面の実装」を入力し「作成」ボタンを押す
Then  タスクが「未着手」ステータスで DB に保存され
  And タスク一覧にそのタスクが表示される
  And 「タスクを作成しました」というフィードバックが表示される
```

### AC-002: 担当者を指定すると通知メールが届く

```gherkin
Given 認証済みユーザーがタスク作成フォームを開いている
When  担当者に「田中 誠（tanaka@example.com）」を選択して作成する
Then  田中 誠 に「タスク『ログイン画面の実装』が割り当てられました」という通知メールが送信される
  And タスクの担当者フィールドに「田中 誠」が表示される
```

### AC-003: タイトルが空のまま作成しようとするとエラーになる

```gherkin
Given 認証済みユーザーがタスク作成フォームを開いている
When  タイトルを空白のまま「作成」ボタンを押す
Then  フォームは送信されず
  And タイトル欄に「タイトルは必須です」というインラインエラーメッセージが表示される
```

### AC-004: タイトルの最大文字数（200文字）を超えると作成できない

```gherkin
Given 認証済みユーザーがタスク作成フォームを開いている
When  201文字のタイトルを入力して「作成」ボタンを押す
Then  「タイトルは200文字以内で入力してください」というエラーが表示される
  And タスクは作成されない
```

### AC-005: 閲覧者（Viewer）はタスクを作成できない

```gherkin
Given ロールが「閲覧者」のユーザーがプロジェクト画面を閲覧している
When  タスク作成を試みる（「タスク追加」ボタンを押す、またはAPIを直接呼び出す）
Then  「この操作を行う権限がありません」というエラーが表示または返却され
  And タスクは作成されない
```

### AC-006: テンプレートからタスクを作成できる

```gherkin
Given 認証済みユーザーがタスク作成フォームを開いている
  And プロジェクトに「バグ報告」というテンプレートが存在する
When  「テンプレートから作成」を選択し「バグ報告」テンプレートを選ぶ
Then  フォームにテンプレートの内容（タイトル・説明・優先度）が自動入力される
  And ユーザーはそれを編集してタスクを作成できる
```

## 補足・制約

- タスクのステータス遷移ルールは BR-1 に定義される（作成時は常に「未着手」）。
- 担当者はプロジェクトメンバーから選択する（外部ユーザーは選択不可）。
- 通知メールの送信失敗はタスク作成の失敗ではない（非同期処理）。
- 参照: [FR-001 Task.Create](../functional/FR-001-タスク管理.md)、[UC-001](UC-001-タスクを作成する.md)
