## 3. セキュリティ（Security）

| 要件ID | 区分 | 要件内容 | 関連標準 |
|-------|------|---------|---------|
| NFR-S-01 | 認証 | JWT Bearer Token / OAuth 2.0 によるAPI認証を実装する | OWASP A07 |
| NFR-S-02 | 通信暗号化 | 全通信をTLS 1.3以上で暗号化する | OWASP A02 |
| NFR-S-03 | データ保護 | 個人情報・機密情報はAES-256で暗号化して保存する | GDPR / 個人情報保護法 |
| NFR-S-04 | アクセス制御 | ロールベースアクセス制御（RBAC）を実装する | OWASP A01 |
| NFR-S-05 | 監査ログ | 認証イベント・データ変更操作を全件記録し90日間保持する | |
| NFR-S-06 | 入力検証 | SQLインジェクション・XSS・CSRF対策を実装する | OWASP Top 10 |
| NFR-S-07 | 秘密情報管理 | 接続文字列・APIキー等はKey Vaultで管理し、コードに埋め込まない | |
